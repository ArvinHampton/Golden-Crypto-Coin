# Zero-budget playbook

Goal: public launch presence **without spending money**. Tradable market comes later when capital exists.

## Free now
1. GitHub docs + contract (done)
2. GitHub Pages landing site (`docs/`)
3. Organic posts once X connection works (or post manually)
4. Community channels you already control
5. Later: free listing applications only after a live pool exists

## Not free (defer)
- Gas for deploy / approve / add liquidity
- Pair asset for a DEX pool (BNB etc.)
- Paid ads, influencers, paid audits
- Stripe products (skipped for now)

## Honest constraint
You cannot create buy/sell depth with $0. Until a pool is funded, market the **project and docs**, not a living market.
